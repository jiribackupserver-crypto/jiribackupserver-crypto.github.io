Privacy Policy

Last updated: November 11, 2026

1. About the Application

Digitalni Druid Backup is a private, self-hosted application used exclusively for personal encrypted server backups. It is not a commercial service and does not accept public registrations.

2. Google Drive Access

The application uses the Google Drive API through rclone to upload and verify encrypted backup files in the owner's Google Drive account.

The requested Google Drive permission technically allows access to files throughout the account. The intended application use is limited to operations necessary for personal backup storage.

3. Data Storage and Security

Backup archives are encrypted locally before being uploaded to Google Drive. Authentication credentials and operational logs are stored on the owner's private server.

4. Data Sharing

The application does not sell personal information, share it with advertisers, or use Google Drive data for advertising or AI model training. Google processes the uploaded encrypted files as the cloud storage provider.

5. Data Retention and Deletion

Backup files remain in the owner's Google Drive according to the configured backup retention policy. The owner may manually delete stored backups and revoke the application's Google account access at any time.

Revoking access prevents further authorized operations but does not automatically delete existing backups.

6. Google API Limited Use

The application's use of information received from Google APIs is intended to comply with the Google API Services User Data Policy, including the Limited Use requirements.

7. Contact

Privacy inquiries may be directed to the developer using the support contact provided on the application's Google OAuth consent screen.
